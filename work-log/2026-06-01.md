## DB 변경 (Supabase에서 이미 실행 완료)
```sql
-- products RLS 정책 수정: 본사 담당자(job_title='담당자')도 INSERT/UPDATE/DELETE 허용
DROP POLICY "products 관리" ON products;
CREATE POLICY "products 관리" ON products
  FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid()
                   AND (role = 'admin' OR job_title = '담당자')))
  WITH CHECK (EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid()
                        AND (role = 'admin' OR job_title = '담당자')));
```
> 본사 담당자 계정(`young@kbh.kr`)에서 상품추가 시 RLS 위반 오류 났던 이슈 해결.
> 다른 테이블(sales, store_stock, store_transfers 등)도 같은 패턴('admin'만 허용)이
> 있을 수 있어 본사 담당자가 막히는 곳 있으면 같은 패턴으로 보정 필요.
