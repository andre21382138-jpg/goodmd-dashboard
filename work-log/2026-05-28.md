## RLS 정책 수정 — products 테이블
**문제**: 본사 담당자(`young@kbh.kr`, `job_title='담당자'`)가 상품 추가 시
`new row violates row-level security policy for table "products"` 오류 발생.

**원인**:
- 기존 `products 관리` 정책이 `role='admin'`만 허용 — 본사 담당자는 매치 안 됨
- `FOR ALL` 정책의 `with_check`가 NULL이라 INSERT 시 무조건 거부

**해결** (실행 완료):
```sql
DROP POLICY "products 관리" ON products;

CREATE POLICY "products 관리" ON products
  FOR ALL TO authenticated
  USING (
    EXISTS (
      SELECT 1 FROM profiles
      WHERE id = auth.uid()
        AND (role = 'admin' OR job_title = '담당자')
    )
  )
  WITH CHECK (
    EXISTS (
      SELECT 1 FROM profiles
      WHERE id = auth.uid()
        AND (role = 'admin' OR job_title = '담당자')
    )
  );
```

다른 테이블(sales, store_stock, store_transfers 등)에도 비슷한 패턴(`role='admin'`만 허용)이 있을 가능성 — 향후 본사 담당자가 어떤 작업에서 막히면 같은 패턴으로 정책 보정 필요.
