# 스크린샷 캡처 가이드

PPT의 회색 `📸 ...` 박스 위치에 실제 앱 화면을 넣으시면 됩니다.

## 캡처 방법

**Windows**: `Win + Shift + S` (스니핑 도구) → 원하는 영역 드래그 → 자동 클립보드 복사
**Mac**: `Cmd + Shift + 4` → 영역 드래그 → 데스크탑에 저장됨

PowerPoint에서 회색 placeholder 박스를 클릭 → `Ctrl+V` 또는 박스 위에 드래그&드롭으로 교체.

## 페이지별 캡처할 화면

매장 매니저 계정으로 로그인 후 캡처 (본사 계정 X — 매니저가 보는 화면이어야 정확함).

### Slide 2 — 로그인 화면 ✅ 이미 자동 캡처됨
- 위치: `training-ppt/screenshots/01-login.png`
- 별도 작업 불필요

### Slide 3 — 출퇴근 패널 (사이드바)
- 매니저 로그인 → 어떤 페이지든 진입 (홈 권장)
- **좌측 사이드바 상단 출퇴근 카드 영역**만 잘라서 캡처
- 노란 사이드바, 출근/퇴근 버튼이 보여야 함

### Slide 4 — 판매 입력
- 좌측 메뉴 → **판매 입력**
- 상품 1개 정도 입력한 상태에서 화면 전체 캡처
- 결제 버튼, 택배 체크박스 보여야 함

### Slide 5 — 반품 접수
- 좌측 메뉴 → **반품 접수**
- 최소 1건 검색 결과가 있는 상태로 캡처

### Slide 6 — 회원 가입 (2개 캡처)
- **QR 가입 화면**: 좌측 메뉴 → 회원 관리 → QR 가입
- **서류 가입 화면**: 좌측 메뉴 → 회원 관리 → 서류 가입
- 각각 따로 캡처해서 해당 placeholder에 삽입

### Slide 7 — 재고 요청
- 좌측 메뉴 → 재고 관리 → **재고 요청**
- 폼 + 요청 이력 테이블이 함께 보이는 화면

### Slide 8 — 입고 확인
- 좌측 메뉴 → 재고 관리 → **발주 확인** → **입고 확인** 탭 클릭
- 도착한 발주가 있는 상태에서 캡처 (없으면 빈 상태 안내라도 OK)

### Slide 9 — 휴무 신청
- 좌측 메뉴 → 근태 관리 → **휴무 신청**
- 다음달 캘린더가 보이는 화면

## 권장 캡처 설정

- **해상도**: 화면 비율 16:9 (전체 브라우저 창)
- **브라우저**: Chrome 또는 Edge, 줌 100%
- **민감 정보**: 캡처 후 실제 고객명/연락처/금액이 보이면 모자이크 또는 가린 후 사용
- **샘플 데이터**: 가능하면 테스트 데이터로 깨끗한 화면 만든 후 캡처

## 캡처 완료 후

1. PowerPoint 열기: `팔레오_매장_매니저_사용가이드.pptx`
2. 회색 박스 위에서 우클릭 → 그림 변경 → 캡처 파일 선택
3. 또는 박스 클릭 후 Delete → 캡처 이미지를 그 위치에 드래그&드롭
4. 전체 한번 슬라이드 쇼로 검토
5. 매장 교육에 활용

## 참고

- 본 PPT는 와이드(16:9) 비율로 제작됨
- 텍스트는 자유롭게 편집 가능 (기능 변경 시)
- 색상 톤: 주황(액센트) + 네이비(타이틀) + 흰색(본문)
